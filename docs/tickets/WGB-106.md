# WGB-106 · Scheduled transfers

**Type:** Feature · **Priority:** Medium · **Component:** `src/transfer.js`

## Story

> "I pay my rent on the first of every month. I'd like to set up the transfer now and have it sent on the right day, instead of remembering to do it."
>
> — Woodgrove customer

## Rules

- A transfer request can have an optional `executionDate` in the format `YYYY-MM-DD`.
- Allowed: from today up to 365 days ahead (compare dates in UTC, based on the `now` passed to `createTransfer`).
- No `executionDate`, or today: the transfer works as it does now (`ACCEPTED`).
- A future date: status `SCHEDULED`, and the transfer includes the `executionDate`.
- A date in the past, more than 365 days ahead, or not a real date: error `INVALID_EXECUTION_DATE`.
- Instant transfers can't be scheduled: error `INSTANT_CANNOT_BE_SCHEDULED`.

## Examples (today is 2026-11-25)

| executionDate | instant | Result |
|---|---|---|
| (none) | no | `ACCEPTED` |
| `2026-11-25` | no | `ACCEPTED` |
| `2026-12-01` | no | `SCHEDULED` |
| `2026-11-24` | no | `INVALID_EXECUTION_DATE` |
| `2027-11-26` | no | `INVALID_EXECUTION_DATE` |
| `2026-02-30` | no | `INVALID_EXECUTION_DATE` |
| `2026-12-01` | yes | `INSTANT_CANNOT_BE_SCHEDULED` |
