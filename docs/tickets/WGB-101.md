# WGB-101 · Some valid French and Italian IBANs are rejected as invalid

**Type:** Bug · **Priority:** High · **Component:** `src/iban.js`

## Story

> "I tried to pay my landlord in Milan and Woodgrove says his IBAN is invalid. I copied it straight from his invoice, and my other bank accepts it without any problem."
>
> — Woodgrove customer, via the service desk

The service desk has seen several of these reports this week, mostly for French and Italian accounts. Transfers to Dutch, German and Belgian accounts work fine.

## Examples

| IBAN | Country | Expected | Today |
|---|---|---|---|
| `FR14 2004 1010 0505 0001 3M02 606` | France | valid | ❌ rejected as invalid |
| `IT21 A030 6909 6061 0000 0063 789` | Italy | valid | ❌ rejected as invalid |
| `FR76 3000 6000 0112 3456 7890 189` | France | valid | ✅ accepted |
| `NL91 ABNA 0417 1643 00` | Netherlands | valid | ✅ accepted |
| `DE89 3704 0044 0532 0130 00` | Germany | valid | ✅ accepted |
| `BE68 5390 0754 7034` | Belgium | valid | ✅ accepted |

## Acceptance criteria

- [ ] All IBANs in the table above are accepted by `isValidIban`.
- [ ] IBANs with wrong check digits are still rejected.
- [ ] A regression test in `tests/iban.test.js` fails before the fix and passes after it.
- [ ] The public API of `src/iban.js` does not change.
- [ ] All tests pass (`node tests/run.js`, or `tests/index.html` in a browser).
